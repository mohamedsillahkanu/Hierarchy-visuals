Key Features

The tool intelligently extracts and validates hierarchical relationships.

Unique Path Extraction - Deduplicates automatically
Interactive Tree View - Expand/collapse nodes
Integrity Checking - Detects data issues
Search & Filter - Find any value quickly
Level-by-Level Export - Separate sheets per level
Column Type Detection - Text vs numeric columns
Tip: The tool detects when the same child value appears under multiple parents (e.g., "Freetown" under both "Western Urban" and "Western Rural") and flags these as potential data quality issues.
